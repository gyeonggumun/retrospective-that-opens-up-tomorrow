# Retrospective That Opens Up Tomorrow

**내일을 여는 회고**는 대학생이 저녁의 긍정적 사건과 원인을 기록하고, 다음 날 중요한 과제를 시작할 자신감을 점검하도록 돕는 React 웹앱입니다. 「긍정적 회고와 다음 날 자기효능감」 연구 프로토콜의 기록 절차를 저위험 개인 기록 흐름으로 옮겼습니다.

공개 웹앱: [retrospective-that-opens-up-tomorro.vercel.app](https://retrospective-that-opens-up-tomorro.vercel.app)

## 기능

- 저녁 회고: 잘된 일 또는 감사했던 일 3개와 이유, 기여 태그 기록
- 아침 체크인: 중요한 과제와 상태 자기효능감(0-10), 정서·난이도·수면 기록
- 기록 확인: 최근 7개 기록의 회고 상태와 자신감 관찰값 표시
- CSV 내보내기와 이 기기의 전체 기록 삭제
- 로그인·서버 전송 없이 브라우저 `localStorage`에만 저장

## 실행 방법

Node.js 20.19 이상이 필요합니다.

```bash
npm install
npm run dev
```

표시된 로컬 URL을 브라우저에서 엽니다. 배포용 결과물은 다음 명령으로 만들 수 있습니다.

```bash
npm run build
```

## 확인 방법

1. 첫 화면에서 논문 제목과 “누구를 어떻게 돕는가” 문장을 확인합니다.
2. 저녁 회고에 사건·이유를 두 개 이상 입력하고 저장합니다. 한 글자만 입력해도 오류 안내가 보이고 앱은 멈추지 않아야 합니다.
3. 아침 체크인에 과제와 자신감 점수를 입력하고 저장합니다.
4. 기록 확인에서 저장한 날짜와 자신감 점수를 확인하고 CSV 내보내기를 실행합니다.
5. 필요하면 “이 기기의 기록 모두 삭제”를 눌러 브라우저 저장 기록을 삭제합니다.

## 개인정보와 해석 원칙

이 앱은 의료적 진단·치료·위기 대응 서비스가 아닙니다. 기록은 기본적으로 사용자의 브라우저에만 저장되며, 앱은 회고가 기분이나 건강을 개선했다고 판단하지 않습니다. 실제 개인정보·API 키·외부 AI 서비스 키를 사용하지 않습니다.

## 과제 13 체크리스트 대응

- 논문 기반 문장과 사용자 행동 3가지: 첫 화면, 저녁 회고, 아침 체크인, 기록 확인에 명시했습니다.
- 논문 방법의 실제 사용: 3개 사건과 이유·기여 태그, 다음 날 과제 자신감 0-10점, 선택적 정서·난이도·수면 기록을 구현했습니다.
- 잘못된 입력 처리: 회고 항목과 과제가 부족하면 안내 문구를 표시하고 앱을 중단하지 않습니다.
- 개인정보·비밀값: 로그인·서버 전송·API 키가 없고 브라우저 로컬 저장과 CSV 내보내기·전체 삭제를 제공합니다.
- 실행 묶음: 저장소의 README 절차를 새 임시 폴더에서 `npm ci`, `npm run build`로 검증했습니다. 제출용 ZIP은 프로젝트 루트 밖에 별도로 만들었습니다.

## AI와 나의 판단

1. AI에게 맡긴 일: React 컴포넌트 구조, 입력 검증, 로컬 저장과 CSV 내보내기 코드 초안을 만들었습니다.
2. 내가 직접 판단한 일: 논문의 관찰연구 범위, 기록 문항, 개인정보 최소화, 치료 효과를 주장하지 않는 화면 문구를 결정했습니다.
3. 따르지 않은 제안: 감정 진단 챗봇·연속기록 경쟁·외부 서버 저장은 연구의 윤리 원칙과 맞지 않아 포함하지 않았습니다.
